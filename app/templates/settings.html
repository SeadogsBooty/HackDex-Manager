Install & Update Safety

These protections are always enforced by HackDex Manager and cannot be disabled.

✓
Verified staging

Patched ROMs and packaged artifacts are hash-verified before any library write.

✓
Atomic installation

HackDex Manager writes to a temporary file, verifies it, and then performs the final placement atomically.

✓
Verified updates

The currently installed ROM is hash-checked before an update begins and checked again before it is retired.

✓
Rollback protection

Same-name replacements use a verified rollback copy so the existing ROM can be restored if final verification fails.

✓
Old versions retire last

An older ROM is removed only after the replacement has been successfully installed and verified.

✓
Collision confirmation

If an unrelated file already uses the intended filename, HackDex Manager asks before replacing it.

✓
Base ROMs stay untouched

Clean base ROMs are used only as patch sources and are never modified.

RomM Users

HackDex Manager does not require RomM and does not connect directly to RomM.

Automatic RomM synchronization

If you use RomM, enable RomM's filesystem watcher. RomM will then detect ROM hacks that HackDex Manager adds, updates, or removes from your library folders.

1. Open your RomM Docker Compose or environment configuration.

Under the RomM container's environment settings, add: 

ENABLE_RESCAN_ON_FILESYSTEM_CHANGE: "true"
RESCAN_ON_FILESYSTEM_CHANGE_DELAY: "5"
2. Recreate or restart the RomM container.

RomM will begin monitoring its library filesystem for additions, updates, moves, and removals.

3. Optional: disable scheduled full-library rescans.

If you do not independently need RomM's scheduled full-library rescan, HackDex Manager recommends leaving it disabled: 

ENABLE_SCHEDULED_RESCAN: "false"
About the watcher delay

RESCAN_ON_FILESYSTEM_CHANGE_DELAY is the delay, in minutes, before RomM processes filesystem changes.

A value of 5 is a good general-purpose setting. You can lower it if you want newly downloaded or updated hacks to appear in RomM sooner.
